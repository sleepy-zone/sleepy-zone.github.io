woocs WeChat Markdown エディタ

woocs

woocs は WeChat 記事向けのデスクトップ Markdown エディタです。doocs/md をベースに、Markdown の下書きを WeChat に貼り付けられるリッチテキストに整えます。

公開中ツール
プロジェクトを開く ↗GitHub ↗すべてのプロジェクト

含まれるもの

  • Vue + Electron のデスクトップアプリ
  • doocs/md ベースの WeChat 向け整形
  • インポート / エクスポートとショートカット

こんな用途に

  • WeChat 記事の整形
  • Markdown メモをリッチテキストに変換
