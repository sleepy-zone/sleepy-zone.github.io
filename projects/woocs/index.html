woocs 微信 Markdown 编辑器

woocs

woocs 是微信 Markdown 编辑器的桌面版，基于 doocs/md，把 Markdown 草稿排成可以直接粘贴到公众号的富文本。

维护中工具★ 73
打开项目 ↗GitHub ↗全部项目

包含什么

  • Vue + Electron 桌面应用
  • 基于 doocs/md 的公众号排版能力
  • 支持导入导出和常用快捷键

适合用来做什么

  • 公众号文章排版
  • 把 Markdown 笔记转成富文本
